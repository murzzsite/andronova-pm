# Елена Андронова: перманентный макияж, Мытищи

Лендинг. Чистый HTML/CSS/JS, без сборки. Заявки идут через lead-relay Worker в Telegram (ref XS3CHUYDMR).

## Что заменить или уточнить
- Фото работ: присланы клиенткой (Яндекс.Диск), остальные с карточки Яндекс.Карт.
- Отзыв: Людмила, реальный, с Яндекс.Карт (рейтинг 5,0, 125 оценок, 84 отзыва на момент сборки).
- privacy.html: самозанятая, ИНН указан.
- Гарантия: после процедуры и коррекции следующая коррекция бесплатно, если результат не устроил или мало виден.

## Дизайн
Направление taste-skill: split-stage (липкое фото справа, смена кадра по секциям). Шрифты Prata + Onest (кириллица), палитра из фирменного логотипа (персик) и мятных стен кабинета.
